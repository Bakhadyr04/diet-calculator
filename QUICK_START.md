# Быстрый старт

## Запуск приложения

### 1. Запустите бэкенд (обязательно!)

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python run.py
```

Бэкенд должен быть доступен на `http://localhost:8000`

### 2. Запустите фронтенд

В другом терминале:

```bash
cd diet-calculator  # если вы не в корне проекта
npm start
# или
npm run web  # для веб-версии
```

### 3. Откройте приложение

- **Web**: http://localhost:8081 (или другой порт, который покажет Expo)
- **Android/iOS**: Используйте Expo Go приложение

## Важно!

⚠️ **Бэкенд должен быть запущен перед запуском фронтенда!**

Без бэкенда приложение не будет работать, так как все данные теперь хранятся на сервере.

## Проверка работы

1. Откройте http://localhost:8000/docs - должна открыться документация API
2. Зарегистрируйтесь в приложении
3. Войдите и создайте расчет

## Устранение проблем

### "Network request failed"
- Убедитесь что бэкенд запущен на порту 8000
- Проверьте что нет ошибок в консоли бэкенда

### "401 Unauthorized"  
- Попробуйте выйти и войти снова
- Проверьте что токен сохраняется в AsyncStorage

### Бэкенд не запускается
- Убедитесь что Python установлен
- Проверьте что все зависимости установлены: `pip install -r requirements.txt`
- Проверьте что порт 8000 свободен
