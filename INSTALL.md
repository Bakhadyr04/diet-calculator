# Инструкция по установке и запуску

## Предварительные требования

1. **Node.js** (версия 14 или выше)
2. **npm** или **yarn**
3. **Expo CLI** (установится автоматически)
4. **Expo Go** приложение на вашем мобильном устройстве (для тестирования)

## Установка

1. Установите зависимости проекта:
```bash
npm install
```

2. Запустите приложение:
```bash
npm start
```

3. Отсканируйте QR-код с помощью:
   - **Android**: Приложение Expo Go из Google Play
   - **iOS**: Камера iPhone (автоматически откроет Expo Go)

## Альтернативные способы запуска

### Запуск на эмуляторе Android
```bash
npm run android
```

### Запуск на симуляторе iOS (только на macOS)
```bash
npm run ios
```

### Запуск в браузере
```bash
npm run web
```

## Структура базы данных

База данных SQLite создается автоматически при первом запуске приложения. Все данные хранятся локально на устройстве.

## Решение проблем

### Ошибка при установке зависимостей
```bash
npm cache clean --force
npm install
```

### Проблемы с Expo
```bash
npx expo install --fix
```

### Очистка кэша
```bash
npm start -- --clear
```
