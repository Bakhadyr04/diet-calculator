# Настройка GigaChat API

## Что такое GigaChat

GigaChat - это генеративная AI модель от Сбербанка, которая используется для анализа диеты пользователя и предоставления персонализированных рекомендаций.

## Получение API ключа

1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru/)
2. Создайте приложение и получите API токен
3. Получите доступ к GigaChat API (может потребоваться подписание договора)

## Настройка

### 1. Добавьте токен в .env файл

Создайте или отредактируйте файл `backend/.env`:

```env
# GigaChat API
GIGACHAT_CREDENTIALS=your-gigachat-token-here
```

### 2. Установите зависимости

```bash
cd backend
pip install -r requirements.txt
```

### 3. Перезапустите бэкенд

```bash
python run.py
```

## Как это работает

1. Пользователь заполняет анкету в калькуляторе
2. При нажатии "Рассчитать" данные отправляются на бэкенд
3. Бэкенд формирует промпт с данными анкеты
4. Промпт отправляется в GigaChat API
5. GigaChat анализирует данные и возвращает:
   - Оценку (score) от 0 до 100
   - Уровень оценки (Отлично, Хорошо, Удовлетворительно, Требует улучшения)
   - Описание оценки
   - Список конкретных рекомендаций
6. Результат сохраняется в базе данных и отображается пользователю

## Fallback режим

Если GigaChat API недоступен или токен не настроен, система автоматически использует локальный алгоритм расчета как резервный вариант.

## Формат ответа от GigaChat

GigaChat должен вернуть JSON в следующем формате:

```json
{
    "score": 75.5,
    "interpretation": {
        "level": "Хорошо",
        "description": "Ваш рацион достаточно близок к средиземноморской диете...",
        "recommendations": [
            "Увеличьте потребление овощей",
            "Добавьте больше рыбы",
            "..."
        ]
    }
}
```

## Устранение проблем

### Ошибка "GIGACHAT_CREDENTIALS не установлен"
- Убедитесь что токен добавлен в `.env` файл
- Проверьте что файл `.env` находится в папке `backend`

### Ошибка "GigaChat API error: 401"
- Проверьте правильность токена
- Убедитесь что токен не истек
- Проверьте права доступа к API

### Ошибка "GigaChat API error: 429"
- Превышен лимит запросов
- Подождите некоторое время или проверьте тарифный план

### Ошибка парсинга JSON
- GigaChat вернул ответ в неожиданном формате
- Система автоматически переключится на локальный расчет
